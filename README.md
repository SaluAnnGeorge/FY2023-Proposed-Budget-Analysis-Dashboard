# 📊 FY2023 Proposed Budget Analysis Dashboard

An interactive **Power BI dashboard** developed to analyze the **FY2023 Proposed Government Budget**. This project transforms raw budget data into meaningful business insights through data cleaning, DAX calculations, and interactive visualizations.

---

## 📌 Project Overview

This project analyzes a government budget dataset containing **11,727 records** across multiple fiscal years (FY2020–FY2023). The dashboard helps users explore budget allocations across departments, divisions, funds, and expenditure categories while identifying trends and supporting financial decision-making.

The report includes executive KPIs, departmental analysis, fund allocation, expenditure analysis, and drill-through functionality for detailed insights.

---

## 🎯 Business Objectives

- Analyze budget allocation across government departments.
- Compare FY2023 Proposed Budget with FY2022 Approved Budget.
- Identify departments with the highest budget allocation.
- Analyze budget distribution by funds and expenditure categories.
- Track budget trends across fiscal years.
- Build an interactive dashboard for financial analysis.
